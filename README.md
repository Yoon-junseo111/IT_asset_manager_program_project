## 개발 진행 상황

### Day 1 - 자산 관리 기본 기능

- HTML/CSS를 활용한 기본 관리 화면 구현
- JavaScript 객체와 배열을 활용한 자산 데이터 관리
- 자산 목록 동적 렌더링
- 신규 자산 등록 기능
- 필수 입력값 검증
- 자산번호 중복 등록 방지
- 자산 삭제 기능
- 자산 상태별 대시보드 통계 구현
- 등록 및 삭제 시 화면 자동 갱신

## 현재 사용 기술

- HTML
- CSS
- JavaScript
